# Maestrr — Versions officielles

Maestrr est une solution auto-hébergée pour installer et utiliser un serveur multimédia personnel : films, séries, animation et musique, avec un dashboard et des intégrations aux applications multimédias.

Ce dépôt public est réservé à la **distribution des versions validées** et à leurs notes de version. Les projets de développement sont hébergés séparément dans les dépôts privés de l'organisation Maestrr-app.

## Téléchargements

Aucune version officielle n'est encore disponible. Les installateurs et archives apparaîtront dans l'onglet **Releases** une fois leur validation terminée.

Les publications comprendront les numéros de version, les nouveautés, les prérequis et les fichiers de contrôle SHA-256. Ne téléchargez pas d'installateur présenté comme officiel en dehors des publications de ce dépôt.

Chaque utilisateur héberge sa propre instance et conserve ses données et connexions localement. Aucun compte ou serveur de commande Maestrr centralisé n'est nécessaire.
